Detailed Description

template<typename Container_>
class jiwoo::Scope< Container_ >

Scope for freeing a container of array pointers.

Template Parameters
Container_Any combination of std::vector and std::optional classes containing pointers to arrays, i.e., from new[].

Each instance of Scope should be bound to a separate instance of a Container_. Once Scope goes out of scope, its destructor will traverse its bound Container_ instance, calling delete[] on all non-NULL array pointers that it can find.
